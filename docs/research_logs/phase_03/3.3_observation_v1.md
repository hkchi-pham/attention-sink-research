# Phase 3.3 - Causal Intervention on the Query Pathway


## Full Query Transplant
### Observation
The donor-recipient scatter points (red) lie almost perfectly on the identity defined by the donor values rather than the recipient baseline.

Every measured quantity—including sink probability, BOS logit, strongest-competitor margin, log-sum-exp margin, entropy and effective competitor number -> shows a transfer fraction of exactly 1.0.

The transfer-depth plot is completely flat at 1.0 across all intervention layers.

## Interpretation
At first glance this appears to demonstrate perfect causal transfer.

However, after inspecting the implementation, this result is expected by construction.

A full query transplant replaces the recipient query vector with the donor query vector while the hidden state entering the layer and the shared KV representations remain unchanged.

Therefore $Q^new_{recipient} = Q_{donor}$ which immediately implies $QK^t_{recipient} = QK^t_{donor}$ and therefore identical attention logits and identical downstream attention probabilities within that layer.

The experiment therefore verifies that the intervention pipeline is implemented correctly rather than establishing a mechanistic property of the model.

The flat transfer curve across depth likewise reflects that each intervention is performed independently at a single layer rather than revealing depth dependence.

### Conclusion

A complete query transplant perfectly reproduces donor attention behavior within the intervened layer.

This confirms the correctness of the intervention framework.

However, because this equality follows directly from the intervention itself, it should be interpreted as a consistency check rather than evidence that query projections alone generate sink behaviour.

## Layer-wise Full Transplants
### Observation
Across almost every layer, the sink score after intervention differs substantially from baseline.

The scatter points are widely dispersed around the identity line.

Some interventions increase sink score whereas others decrease it.

The magnitude of the changes appears larger in middle and later layers.

### Interpretation
Unlike the first experiment, this experiment compares intervention outputs against each head's own baseline instead of the donor reference.

Consequently it reveals the actual sensitivity of sink behaviour to modifying the query pathway.

The bidirectional changes indicate that replacing a query projection can either strengthen or weaken sink formation depending on the original functional specialization of that head.

The absence of a systematic upward or downward shift suggests that the intervention transfers specialization rather than simply increasing attention to BOS.

The larger deviations observed in deeper layers are consistent with sink behaviour becoming progressively more specialized during depth.

### Conclusion
Replacing the query pathway substantially alters sink behaviour across the network.

The query pathway therefore contributes causally to sink specialization, although its influence depends on layer and head identity rather than acting as a universal amplifier.

## Query Ablations
### Observation
Most perturbations produce only modest reductions in average sink score.

Adding Gaussian noise, scaling the query by 0.5 or 2, or normalizing the query all leave the sink score relatively close to baseline.

However, completely zeroing the query reduces the sink score almost to zero.

### Interpretation
Scaling Q→cQ changes every attention logit by the same multiplicative factor $QK^t → cQK^t$ 

This changes the temperature of the attention distribution but largely preserves the relative ordering of logits. The modest behavioural changes therefore suggest that sink formation depends primarily on the geometric direction of the query representation rather than its overall norm.

Similarly, query normalization preserves direction while removing only magnitude information.

The relatively small changes therefore indicate that sink specialization depends primarily on query direction rather than query norm.

Only removing the query entirely destroys sink behaviour. Thus the information encoded in the orientation of the query vector(not just magnitude) is essential for producing sink attention.

### Conclusion
Sink formation is highly robust to changes in query magnitude but highly sensitive to removing the query representation altogether.

This suggests that sink specialization is encoded predominantly in the directional structure of query representations.

## Ripple Analysis
### Observation
Immediately after intervention (distance = 0), transfer equals 1 as expected. However, transfer drops sharply after one subsequent layer.

Beyond approximately one or two downstream layers, the mean transfer fluctuates around zero with large variance.

The heatmap likewise shows a bright diagonal confined to the intervention layer while almost all off-diagonal entries remain near zero.

Only isolated patches exhibit weak downstream propagation.

### Interpretation
This is the first genuinely non-trivial causal result.

Although the transplanted query completely determines attention inside the patched layer, that information is not preserved throughout the remaining transformer.

Residual connections, MLP updates and newly computed query projections progressively overwrite the transplanted representation. Thus the network rapidly reconstructs its own internal dynamics.

The occasional weak propagation events indicate that some perturbations survive briefly, but there is no evidence of long-range persistence.

### Conclusion
The causal influence of a query transplant is highly local.

Query information propagates only weakly beyond the intervention layer, indicating that sink specialization is repeatedly reconstructed throughout the network rather than inherited unchanged from earlier layers.

This result argues against the existence of a single "sink layer" responsible for downstream behaviour.

## Partial Query Transplants
### Observation
Increasing the interpolation coefficient initially increases transfer, BOS logit and sink score. However, the relationship is distinctly nonlinear.

Transfer exceeds the expected linear interpolation between approximately α=0.25 and α=0.75, before returning to the expected value at α=1.

Large error bars indicate considerable variability across intervention sites.

### Interpretation
If sink specialization depended linearly on the query representation, transfer should closely follow transfer=α.

Instead, intermediate mixtures produce disproportionately large behavioural changes. 
The observed deviation from linear transfer reflects the nonlinear mapping from attention logits to attention probabilities. Whether this nonlinearity arises solely from the softmax transformation or additionally reflects nonlinear representational interactions cannot be determined from this experiment alone.

Small directional changes in query space can therefore reorganize attention more strongly than expected from linear interpolation.

The substantial variance further indicates that this nonlinearity depends on the particular layer and head being modified.

### Conclusion
Sink specialization varies continuously with the query representation but does not scale linearly.

Intermediate query mixtures can produce amplified behavioural changes, implying nonlinear interactions between queries and the shared KV representations.

## Layer-wise Ablation Profiles
### Observation
Noise injection causes an exceptionally large increase in relative sink score only at Layer 0 before rapidly returning to baseline.

Zeroing the query likewise produces a strong effect in the earliest layers but rapidly approaches baseline afterwards.

Scaling and normalization remain close to baseline throughout all layers.

### Interpretation
The earliest layer appears uniquely sensitive to perturbations because it operates directly on token embeddings before higher-level representations have formed.

Introducing random noise at this stage perturbs all subsequent computations, whereas later layers receive increasingly structured residual representations that are more robust to local perturbations.

The fact that scaling and normalization remain largely unchanged again reinforces that sink specialization is insensitive to simple changes in query magnitude.

### Conclusion
Early layers are substantially more vulnerable to destructive perturbations than later layers.

Once contextual representations have formed, sink behaviour becomes increasingly robust to moderate changes in query magnitude, further supporting the view that specialization is encoded in learned representational geometry rather than absolute query scale.

## Conclusion
The query pathway is the immediate determinant of sink behaviour within an attention layer, but its causal influence is highly local. Sink specialization is repeatedly reconstructed across depth through successive query computations rather than permanently inherited from a single query projection. Moreover, sink behaviour depends primarily on the directional structure of query representations, while remaining largely invariant to query magnitude.
