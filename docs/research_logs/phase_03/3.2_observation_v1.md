# 3.2 Origin of Within-Group Specialization

## Query vector magnitude
### Observation
The figure represents the distribution of query vector norms for every attention head, grouped according to their shared KV representation. Across almost all heads, the distributions overlap substantially, with median query norms lying within a relatively narrow range(approximately 13 -> 16). 
Although some individual heads exhibit slightly larger variance or higher upper tails(head 7), no KV group consistently produce substantially larger query vectors than the others

For every layer, the difference between the largest and smallest query norm inside each shared-KV group remains relatively modest. While occastionally spikes appear in isolated layers, no monotonic increase or persistent separation is observed as depth increases. Instead, within-group query magnitudes fluctuate around similar values throughout the network.

## Interpretation
SInce all heads sharing a KV group receive identical KV projections, one possible explanation for their differeing sink behavior would be the differences in the overall strength of their query vectors. Larger query magnitudes would scale all dot products proportionally, potentially leading to more confident attention distribution after the softmax.

However, the observed distributions provide little evidence for this hypothesis. Query magnitudes remain remarkably similar across heads, both globally and within individual KV groups. The occasional spikes appear isolated rather than systematic and therefore cannot explain the consistent specialization observed in Phase 3.1.

This suggests that specialization is unlikely to arise from how large the query vectors are. Instead, it is more likely to depend on where the query vectors point in representation space, i.e., their directional alignment with the shared K vectors.

## Conclusion
The overall magnitude of the query vectors does not appear to be the primary mechanism underlying within-group sink specialization. Since heads with nearly identical query norms nevertheless exhibit different sink behaviour, the source of specialization must originate from finer structural properties of the query representations rather than simple vector scaling.

This naturally motivates Analysis 2, which examines whether differences are already present in the raw query-key compatibility scores before the softmax operation.

## Raw QK^t Compatibility
### Observation
I visualises the raw compatibilty matrices $QK^t$ for pairs of heads sharing the same KV representation at early (Layer 0), middle (Layer 14), and late (Layer 27) depths.
Because the compared heads use identical Key matrices, any differences between the heatmaps must arise solely form their Query projections.

The heatmaps reveal that the overall spatial structure remains highly similar across shared-KV heads. Altough, the difference mapps demonstrate numerous localised deviations throughout the sequence, perticularly in th eiddle and deeper layers. These deviations are not random isolated pixels but exhibit coherent regional patterns, indicating systematic differences in QK interaction.

Then I quantifies this observation by computing the Pearson correlation between raw compatibility matrice within every KV group. Correlations remain consistently high through out the network, typically between 0.7 and  0.9, indicating that shared KV heads preserve broadly similar compatibility structures. However correlations never approach unity and remain substantially below perfect agreement, confirming that measurable differences exist despite identical keys.

### Interpretation
These results localise the emergence of specialisation to the QK interaction itself

If the two heads were functionally identical prior to softmax, their raw compatibility matrices would be nearly identical because they share the same Keys. But systematic differences already appear before masking or normalisation.

Importantly, these differences emerge before any nonlinear operation is applied. So the subsequent softmax is not creating specialisation from identical inputs, but the differences are already encoded in the Query projections.

The consistent, high correlations implies an interesting imbalance between shared computation and specialisation. Shared keys enforce a common course compatibility structure, while independent Query projections introduce fine-grained modifications to that structure.

### Conclusion
Within-group specialization originates upstream of the softmax operation. Independent query projections generate distinct compatibility patterns even when Key and Value representations are shared.

This significantly narrows the possible source of sink specialization. Since the divergence already exists in the raw compatibility scores, later stages of the attention computation can only amplify or reshape differences that are already present.

The remaining question is whether these compatibility differences specifically increase attraction toward the BOS token or instead reduce competition from other tokens.

## BOS Competition
### Observation
I defined "sink head" as the top 25% of heads by mean BOS probability.

Then compares the distribution of BOS advantage, defined as the difference between the BOS logit and the strongest competing token. Sink heads and non-sink heads exhibit broadly overlapping distributions, with both concentrated near zero and possessing long negative tails corresponding to tokens where BOS is not the strongest competitor.

I decomposes this advantage into its two constituent somponents. Sink heads exhibit a slightly larger average BOS logit than non-snik heads. However, they also exhibit a slightly larger strongest competing logit. Consequently, the increase in BOS preference is accompanied by a comparable increase in competing token activations rather than a selective suppression of competitors.

At last, I compares BOS advantage against sink score across all heads. No clear monotonic relationship is observed. Heads with similar sink scores span a wide range of BOS advantages, indicating considerable variability beyond this simple metric.

### Intepretation
The decomposition suggests that isnk specialisation cannot be explained solely by stronger BOS attraction

Although sink heads assign marginally higher compatitibility to BOS, they also assign higher compatibility to competing tokens. Consequently, the BOS advantage changes only modestly.

This indicates that sink behaviour is not produced by a simple "boost BOS" mechanism nor by uniformly suppressing alternative tokens. Instead, specialization appears to emerge from a more complex redistribution of compatibility across many tokens simultaneously.

The weak relationship between BOS advantage and sink score further supports this interpretation. While BOS competition contributes to attention allocation, it does not fully determine sink strength.

### Conclusion
Simple BOS-versus-competitor statistics explain only a limited portion of within-group specialization. Sink heads do not appear to specialize exclusively by increasing BOS attraction or suppressing competing tokens in isolation.

Instead, specialization likely reflects richer changes in the entire compatibility landscape produced by the learned query representations.

This motivates examining how these differences evolve throughout the network depth.

## Divergence Through Depth
### Observation
I tracks three measures of similarity between heads sharing identical KV representations across network depth: cosine similarity of query vectors, correlation of raw compatibility matrices, and correlation of BOS logits.

All three metrics exhibit a remarkably consistent trajectory. Similarity is comparatively low in the earliest layers, increases steadily through the middle of the network, reaches its highest values around Layers 12–18, and then decreases again in the final layers.

Despite these common trends, none of the metrics approach perfect similarity. Even when compatibility correlations exceed 0.8, measurable differences persist between heads sharing the same KV. Similarity remains consistently well below one throughout the network.

### Interpretation
This depth-dependent trajectory suggests that specialization is neither present from initialization nor produced monotonically throughout the network.

Instead, the middle layers appear to construct increasingly similar shared representations within each KV group, likely reflecting common contextual information extracted through the shared Key projections.

The subsequent decline in similarity during the deepest layers indicates renewed functional differentiation. Once strong shared representations have been established, independent query projections increasingly reshape how each head interacts with those representations, producing distinct compatibility patterns despite identical Keys.

### Conclusion

Within-group specialization develops progressively throughout the network rather than existing from the earliest layers. Shared-KV heads first converge toward common representations before diverging again during later processing stages.

Taken together with the previous analyses, these results strongly suggest that the independent query pathway is the principle source of within-group functional specialisation.

## Conclusion
Phase 3.2 localises the origin of within-group specialisation to the query pathway of attention. Although heads within a GQA group share identical KV representations, they do not share identical query projections. Differences in query magnitude are insufficient to explain specialisation, whereas systematic differences already appear in raw QK^t compatibility matrices before any masking or softmax normalisation is applied.

The consistently high(but never perfect( correlations between shared-KV heads indicate that shared Keys impose a common compatibility structure while independent query projections introduce head-specific modifications.
These differences persist throughout the network despite substantially similarity between heads, demonstrating that shared memory representations constrain but do not determine attention behavior.

Together with the findings of Phase 3.1, these results identify the learned query projection as the primary source of functional specialization within GQA. Shared KV representations provide a common representational substrate, whereas the independent query pathway determines how each head interrogates that shared memory, ultimately producing distinct sink behaviour.
