A personal research and experimentation repository documenting my journey of studying transformer architectures through Andrej Karpathy's nanoGPT implementation.

This repository serves two purposes:

- **Learning Repository** – detailed notes, explanations, and code walkthroughs while studying how GPT models are built and trained.
- **Research Sandbox** – experiments and investigations that prepare for my independent research project on Attention Sinks in Transformers.

**Learning Goals**
- Understand transformer architecture from first principles
- Read and annotate nanoGPT source code
- Learn how language models are trained end-to-end
- Understand optimization techniques used in modern LLM training
- Build intuition for attention mechanisms and model behavior
